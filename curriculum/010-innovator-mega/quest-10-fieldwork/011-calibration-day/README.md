# Mission `011` — Calibration Day

[Quest `10` — Fieldwork](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

Every device in the class sampling outdoor air at the same agreed minute — the one quantity that is very nearly identical in all their homes — the spread between them measured, and each student's own offset written down and applied in code from then on

## Concepts and standards

- Accuracy versus precision; systematic error versus noise
- Calibrating against a known baseline, and recording the correction rather than hiding it
- A sensor that infers a quantity from a proxy, drifts, and has to be re-baselined
- Cross-checking temperature against the local weather service, over the network set up in mission `000`
- Why a dataset without calibration cannot be pooled
- NGSS practice: **planning and carrying out investigations**; CSTA 2‑DA‑08

## Materials

- M5StickS3 from Quest `01` — the device brought to the session
- ESP32 dev board and breadboard from Quest `00`, set up once at home as the fixed logger
- Environment pack — VOC/eCO₂ gas sensor, temperature, humidity and pressure unit, light sensor, sound sensor, Grove and Grove-to-jumper cables
- Home Wi-Fi, and the instructor-hosted class broker and dashboard
- Laptop running Thonny
- An openable window or a doorstep, and an agreed minute for the whole class to sample at
