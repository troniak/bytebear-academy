# Mission `010` — A Format the Class Agrees On

[Quest `10` — Fieldwork](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

A message format the class negotiates and writes down — device, time, quantity, value, unit, version — sent as JSON by both of the student's boards, with an agreed answer to what a receiver does when a field is missing

## Concepts and standards

- A protocol is an agreement, not a library
- One format, two devices with different jobs: why it has to be agreed rather than assumed
- JSON; units and timestamps as part of the reading rather than an afterthought
- Versioning, and staying strict in what you send and generous in what you accept
- CSTA 2‑DA‑07, 2‑AP‑19
