# Mission `000` — Joining the Network

[Quest `10` — Fieldwork](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

The device joined to home Wi-Fi from MicroPython, its address printed, the clock set from the internet, and the password moved out of the program into a file that never leaves the device

## Concepts and standards

- `network.WLAN`, association, DHCP, and what an IP address actually is
- Why a timestamp is worthless until the clock is right
- Secrets kept out of code that gets shared, pasted or handed in
- CSTA 2‑NI‑04, 2‑NI‑05
