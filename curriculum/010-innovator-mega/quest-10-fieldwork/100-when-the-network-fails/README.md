# Mission `100` — When the Network Fails

[Quest `10` — Fieldwork](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

Three failures caused on purpose — Wi-Fi pulled, broker stopped, device rebooted — and a logger that survives all three, buffering readings while it is offline and sending them when it returns

## Concepts and standards

- Retries, backoff and timeouts
- Buffering to flash, and clock skew between devices
- Telling a dead node apart from a quiet room
- CSTA 2‑CS‑03, 2‑NI‑04
