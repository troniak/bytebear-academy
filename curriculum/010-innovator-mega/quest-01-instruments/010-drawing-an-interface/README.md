# Mission `010` — Drawing an Interface

[Quest `01` — Instruments](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

A reading shown three ways on the same screen — as a number, as a bar and as a needle — and a judgement about which of the three can be read at arm's length in one second

## Concepts and standards

- A screen is a grid of pixels you lay out: coordinates, colour, type size
- Redrawing without flicker, and only redrawing what changed
- Designing for a glance rather than for a demonstration
- STEL practice: **creativity**; STEL core concept: **design in technology and engineering**
