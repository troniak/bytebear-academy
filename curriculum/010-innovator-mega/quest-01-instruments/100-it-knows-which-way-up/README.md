# Mission `100` — It Knows Which Way Up

[Quest `01` — Instruments](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

A spirit level and a shake counter built from the six-axis IMU, with the raw signal charted next to a smoothed one so the student can see what the averaging removed

## Concepts and standards

- Accelerometer versus gyroscope: what each one actually measures
- Noise, and a running average as the cheapest filter there is
- Thresholds on a smoothed signal, and the lag that smoothing costs you
- NGSS core ideas: **forces and motion**; CSTA 2‑DA‑08
