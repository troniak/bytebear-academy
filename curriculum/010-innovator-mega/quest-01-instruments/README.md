# Quest `01` — Instruments

Quest `00` ends with a breadboard that works. This quest asks a harder question: what turns a working circuit into a device somebody would carry? The M5StickS3 is the answer in physical form — the same MicroPython the students already write, but in a case, with a colour screen, an IMU, a microphone, a battery and a Grove socket on the bottom. Nothing here is soldered or wired. The engineering moves up a level instead: laying out a display that can be read in one glance, structuring a program as states rather than a straight line, putting several devices on two shared wires, smoothing a signal that will not sit still, and making 250 mAh last a day.

**Required add-on:** the M5 pack — an M5StickS3 (or M5Stack's current Stick; the StickC PLUS2 it replaced went end-of-life, so check the shop rather than the model number) and one Grove time-of-flight distance unit. The Stick runs M5Stack's UIFlow2 firmware, which is MicroPython with an `M5` library on top; students keep working from Thonny over USB, or from the UIFlow2 console. Its Grove port is the socket every later add-on plugs into.

**About £29** at UK retail — the Stick about £21, the distance unit about £8 — the same spend as the Quest `00` kit.

**Builds on Quest `00`:** the same MicroPython and the same I²C, one library deeper and in a case. Mission `001` opens the Grove connector up and finds the four wires students already know. **Builds on Quest `00`.** The same chip family, the same MicroPython, the same I²C — now in a case, with a screen, a battery and a Grove socket. Meeting the bare board first is what makes this one legible: mission `001` opens the Grove connector up and finds the four wires the student has already stripped by hand. **Carried forward:** from here the Stick is the device that comes to class, and the only one in the realm that needs charging. Its Grove port takes Quest `10`'s sensors and Quest `11`'s camera; its header pins drive Quest `11`'s servos.

Mission `101` is the one families notice. A device that runs for twenty minutes is a project; a device that runs all day is a product, and the difference is entirely decisions the student makes — screen brightness, how often the sensor is read, whether the processor sleeps between readings. It is also the first time in the program that a measurement of their own code changes their design.

**The unlock.** Mission `111` ends with the environment pack handed over. A student who has just presented an instrument with nothing to measure is given four things worth measuring, and the next quest's question along with them.
