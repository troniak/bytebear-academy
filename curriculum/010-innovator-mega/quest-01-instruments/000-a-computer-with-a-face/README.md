[Quest `01` — Instruments](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

The Stick flashed and running the student's own code — their name on the colour screen, both buttons doing something, and the whole thing unplugged and still working

## Concepts and standards

- The same MicroPython one library deeper: what an `M5` wrapper is doing underneath
- A dev board versus a device: case, battery, screen, power button
- Flashing with M5Burner, then working from Thonny or the UIFlow2 console
- CSTA 2‑CS‑02
