# Mission `011` — Menus Are State Machines

[Quest `01` — Instruments](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

Four modes on two buttons — a menu the student can move through and come back from — written around a state variable rather than a growing pile of conditionals

## Concepts and standards

- State machines: what the device is doing now, and what each button means there
- Dispatching on state instead of nesting `if` blocks
- Decomposition — one function per mode, none of them longer than the screen
- CSTA 2‑AP‑12, 2‑AP‑13
