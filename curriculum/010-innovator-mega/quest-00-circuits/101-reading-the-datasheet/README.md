# Mission `101` — Reading the Datasheet

[Quest `00` — Circuits](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

A sensor nobody has demonstrated, wired and read correctly — pinout, supply voltage and timing taken from its datasheet, with a driver library imported and credited

## Concepts and standards

- Reading a pinout, an absolute-maximum table and a timing diagram
- Using and attributing an existing library instead of writing one
- 3.3 V parts versus 5 V parts, and what a level shifter is for
- CSTA 2‑AP‑16, 2‑CS‑02
