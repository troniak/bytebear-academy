# Mission `011` — Loops, Conditions, Functions

[Quest `00` — Circuits](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

The growing program restructured into functions with parameters, a `while True` loop that reads a button through a pull-up resistor, and a bounce the student can see and then fix

## Concepts and standards

- Functions, parameters and return values in text
- `while True` with `time.sleep` — the shape of nearly every embedded program
- Pull-ups, floating inputs and switch bounce
- CSTA 2‑AP‑14, 2‑AP‑12
