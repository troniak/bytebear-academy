# Mission `000` — Hello, REPL

[Quest `00` — Circuits](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

MicroPython flashed onto the board and a live prompt that answers back — the onboard LED switched on by a line the student types rather than a program they run

## Concepts and standards

- The REPL as a conversation with the board, not a program
- `machine.Pin` — a pin is an object whose value you set
- Flashing firmware, choosing a port, and what to do when the board does not appear
- CSTA 2‑CS‑02
