# Mission `110` — When the Circuit Disagrees with the Code

[Quest `00` — Circuits](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

Four boards broken on purpose — a floating input, a missing ground, a wrong pin and a brownout — each diagnosed in writing by a method rather than by guessing

## Concepts and standards

- A debugging method: check power first, halve the system, one change at a time
- Symptoms that look like software and are not
- Reading the board's own error output, and what a reset loop is telling you
- CSTA 2‑CS‑03
