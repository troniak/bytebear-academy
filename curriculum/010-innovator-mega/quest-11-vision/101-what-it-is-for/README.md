# Mission `101` — What It Is For

[Quest `11` — Vision](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

A one-page brief and a first prototype: who the machine is for, what it must do, what it is allowed to get wrong, what it does when the model is unsure, and the test that decides it is finished — built on the Stick, with everything the student owns from the earlier quests available to widen it

## Concepts and standards

- Requirements and constraints; agreeing "done" before anything is built
- Designing the uncertain case on purpose rather than discovering it in the demo
- Pod roles and a project log kept as you go
- Designing with what you already own: camera, screen, servos, sensors, a broker, and the Maker rover if it needs to move
- NGSS practice: **defining problems**; CSTA 2‑AP‑18; STEL practice: **critical thinking**

## Materials

- Vision pack — Grove Vision AI V2 module and OV5647 camera, unassembled pan-and-tilt bracket, two micro servos, 4×AA holder as the servo supply
- M5StickS3 from Quest `01` — the one device the build runs on
- Optional second node: the ESP32 from Quest `00`, the sensors from Quest `10`, the Maker rover
- Laptop with a browser for SenseCraft, and Thonny
- Grove-to-jumper conversion cables, and the tested MicroPython driver from the quest folder
