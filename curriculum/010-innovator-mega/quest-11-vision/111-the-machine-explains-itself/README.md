# Mission `111` — The Machine Explains Itself

[Quest `11` — Vision](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

**Build and show.** The finished machine demonstrated live, with every student presenting their own contribution, how the model was trained, and one thing it reliably gets wrong and why

## Concepts and standards

- NGSS practice: **designing solutions and communicating results**
- STEL practice: **collaboration & communication**
- AI literacy: **Use** — building with a model and explaining it honestly

## The unlock

Nothing to open. This is the last mission of the realm, so the handover is a question rather than a box: the model in the machine runs on a chip somebody else prepared it for, and the student deployed it without ever seeing the code that does the looking. In the Engineer realm they write that themselves, on a Raspberry Pi carrying its own Linux and its own camera, and the first thing they are asked is what the module had been doing for them all along. Students continuing are shown the Pi; what they take home tonight is the machine they built.

- M5StickS3 from Quest `01` — the one device the build runs on
- Optional second node: the ESP32 from Quest `00`, the sensors from Quest `10`, the Maker rover
- Laptop with a browser for SenseCraft, and Thonny
- Grove-to-jumper conversion cables, and the tested MicroPython driver from the quest folder
