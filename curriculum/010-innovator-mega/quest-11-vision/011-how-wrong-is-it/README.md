# Mission `011` — How Wrong Is It?

[Quest `11` — Vision](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

The student's model tested on images it never saw, its confusions written into a table, and a confidence threshold chosen deliberately — with the cost of a false alarm weighed against the cost of a miss

## Concepts and standards

- Hold-out testing; overfitting to your own bedroom
- A confusion matrix says more than an accuracy figure
- Choosing a threshold is choosing which mistake you would rather make
- CSTA 2‑DA‑09; AI literacy: **Evaluate**
