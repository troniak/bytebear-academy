# Mission `001` — Talking to the Module

[Quest `11` — Vision](../README.md) · [Innovator Realm (Mega)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

Detections read into MicroPython on the student's own board — class, confidence and box coordinates arriving as numbers they can print, with the supplied driver read and annotated rather than written

## Concepts and standards

- Reading somebody else's driver and a protocol document, and crediting both
- A device on the bus at a fixed address; bytes in, meaning out
- Image coordinates: origin, width, height, and the centre of a box
- CSTA 2‑AP‑16, 2‑DA‑07
