# Mission `110` — Break It and Improve It

[Quest `11` — Machines](../README.md) · [Maker Realm (Kilo)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

Their machine handed to another pod to test, every failure logged, and one improvement made and measured against the brief from mission `100`

## Concepts and standards

- Testing by someone who did not build it
- iteration with evidence
- CSTA 2‑AP‑17, 2‑CS‑03
