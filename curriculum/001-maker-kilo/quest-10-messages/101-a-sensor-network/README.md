# Mission `101` — A Sensor Network

[Quest `10` — Messages](../README.md) · [Maker Realm (Kilo)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

One device outdoors or in another room reporting readings to the other, the halo showing the live value, and the class aggregating results

## Concepts and standards

- Distributed data collection
- CSTA 2‑CS‑02, 1B‑DA‑06
- NGSS practice: **analyzing and interpreting data**
- AI literacy: **data privacy** — what a network of home sensors would reveal
