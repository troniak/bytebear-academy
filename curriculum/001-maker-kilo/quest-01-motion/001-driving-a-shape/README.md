# Mission `001` — Driving a Shape

[Quest `01` — Motion](../README.md) · [Maker Realm (Kilo)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

A route program that drives a square on a taped course, with turn timings tuned until the rover comes back to its start

## Concepts and standards

- Sequence with duration
- why the same program lands somewhere different each run
- NGSS core ideas: **forces and motion**
