# Mission `000` — Rover, Meet micro:bit

[Quest `01` — Motion](../README.md) · [Maker Realm (Kilo)](../../README.md) · [Curriculum](../../../README.md)

## What the student makes

The rover assembled, the micro:bit seated, and a first program that drives forward for one second and stops

## Concepts and standards

- Outputs that move things
- motor power is not speed
- safe start and stop as a habit
- CSTA 1B‑AP‑10
